Self-Hosted Artifact Registry

Store, version, and distribute tools, models, runtimes, and binaries with immutable packages, RBAC, and OIDC auth.

Get Started View on GitHub

Core Features

Immutable Packages

Strict SemVer with enforced immutability. Published versions cannot be mutated — fixes require a new version.

CLI-First

Resolve, fetch, install, check, and update workflows designed for agents and CI pipelines with --json output.

RBAC & OIDC

Role-based access control with OIDC for production auth, scoped tokens for agents, and gated dev auth.

Private by Default

Raw artifact URLs require auth. Namespaces and packages can be explicitly public like public GitHub repos.

Self-Hosted Binary

Single Go binary serving JSON APIs, raw artifacts, health/metrics, and an embedded React SPA.

PostgreSQL Storage

Artifact bytes stored in PostgreSQL bytea with S3-compatible storage ready for near-future support.
